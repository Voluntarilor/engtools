# EngTools

Инженерный помощник — набор калькуляторов для быстрого доступа с ПК, планшета и телефона.

## Модули

- **Гидравлика** — диаметры, скорости, потери напора
- **LMTD** — температурный напор и тепловая мощность
- **Теплофизика** — свойства воды
- **Конвертер** — перевод единиц

## Как добавить новый модуль

1. Создать файл `js/modules/имя.js` с функцией `renderИмя(root)`, которая
   заполняет `root.innerHTML` и навешивает обработчики.
2. Зарегистрировать модуль в `js/registry.js`: добавить импорт и объект в `MODULES`.
3. Готово — карточка появится на главной автоматически.

## Публикация

1. Залить репозиторий на GitHub.
2. Settings → Pages → Source: `main`, папка `/ (root)`.
3. Открыть `https://логин.github.io/имя-репозитория/`.

## Локальный запуск

Просто открыть `index.html` в браузере. Для проверки PWA-режима — поднять
локальный сервер, например: `python -m http.server 8000`.
